# Observatório Paulo Lemos

Painel público de consulta à agenda, às proposições, aos gastos e às comissões do deputado Paulo Lemos. Os dados são obtidos da API de Dados Abertos da Câmara dos Deputados.

Para executar localmente com Node.js 24, instale as dependências com `npm install` e rode `npx vite`. Use `npm run build` para gerar os arquivos estáticos em `dist/`.
